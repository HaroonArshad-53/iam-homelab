# IAM Homelab

Teaching myself identity & access management by building a lab and working through it.

I'm a CEH working in public-safety ops, moving toward defensive security with IAM as my specialty. This is where I get hands-on with the concepts — directories, authentication, access reviews, and identity attack detection — instead of just reading about them.

## Setup

- **On-prem:** Windows Server 2022 (trial) as domain controller + a Windows 10/11 client, on VirtualBox
- **Cloud:** Microsoft Entra ID free tier for the cloud side (MFA, Conditional Access)
